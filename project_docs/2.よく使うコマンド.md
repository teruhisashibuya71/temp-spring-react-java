# よく使うコマンド

## プロジェクトルート

```bash
# BE / FE 両方の OpenAPI コード生成（一括）
./scripts/generate-api.sh
```

## バックエンド

```bash
cd backend
./gradlew openApiGenerate
./gradlew clean openApiGenerate
./gradlew build
./gradlew bootRun    # http://localhost:8080
```

## フロントエンド

```bash
cd frontend
npm install          # 初回のみ
npm run generate-api-types
npm run dev          # http://localhost:3000
npm run build
```

## OpenAPI 駆動の開発フロー

1. `backend/src/main/resources/openapi.yaml` を編集
2. `./scripts/generate-api.sh` を実行（または BE / FE 個別に generate）
3. BE: 生成 interface を implements する Controller を実装
4. FE: `src/types/generated` の型・クライアントを利用
5. BE `bootRun` + FE `npm run dev` で動作確認
